Overview
What this is: A 4-phase chart transition animation that plays when the user toggles between W (wealth-adjusted) and full portfolio views. The loading state is communicated through a white glow strobe; settlement through a gold sweep + shape morph directly into the final SVG line.

Phase 1 — Fade linear
Line color transitions from gold rgba(199,168,101,1) → white rgba(255,255,255,0.9). Glow alpha 0 → 0.7, glow blur 0 → 14px. Shape stays locked to the current ("from") chart. Canvas owns the render.
380ms → data
Phase 2 — Loading Pulse half-wave sine
White line pulses with a strobe-style blink: only the positive half of a 6 rad/s sine wave is used (clamp negatives to 0). Glow blur 4–20px, line alpha 0.60–0.90. "Updating data…" text fades in at 1.5s. Duration is unbounded — ends the moment data arrives.
0 → 380ms after data
Phase 3A — Gold Sweep linear
A gold frontier sweeps left → right across the current shape (no morphing yet). Behind the frontier: gold line. Ahead: white line. A bright white dot (radius 2.5px, glow 28px) marks the frontier. Duration: SETTLE × 0.4 = 380ms.
380 → 950ms after data
Phase 3B — Shape Morph cubic ease-out
The line shape morphs point-by-point from the old chart to the new chart. All-gold throughout. 181 sample points lerped: p = easeOutCubic(t) where p ∈ [0,1]. Duration: SETTLE × 0.6 = 570ms.
at t=1.0
Handoff — same frame
When morphP reaches 1.0, in the same execution frame: reveal SVG line (already at exact destination), clearRect canvas, hide skeleton. Then fade fill area opacity 0 → 1 over 200ms. No crossfade — the swap is imperceptible because canvas + SVG match exactly.

Chart Paths
line-w (W chart)
13 cubic bezier segments (C commands). Smooth, gradual slope. Sampled to 181 equidistant points by arc length.
line-full (full chart)
~50 straight-line segments (M + L commands). Higher detail, more volatile shape. Sampled to 181 equidistant points by arc length.
Sampling method
SVGPathElement.getTotalLength() + getPointAtLength(i/N × totalLen) for i in 0..N. N=180 gives 181 points.
Morph interpolation
Linear lerp between corresponding sampled points: x = from.x + (to.x − from.x) × p, same for y.

Glow System (Two-Pass)
How it works: Every line stroke is drawn twice using the same path. The first pass sets a large shadowBlur for the diffuse glow halo. The second pass reuses the same beginPath() and sets shadowBlur × 0.3 for a tight inner core glow. This creates a layered appearance: soft outer halo + bright inner line.

React Native Implementation
Recommended stack: @shopify/react-native-skia for canvas equivalent (Path, Paint, BlurMaskFilter, Canvas) + react-native-reanimated for animation values. Skia runs on the UI thread — no JS bridge overhead during animation frames.
RN Skia: Glow (two-pass equivalent)
// Two-pass glow in Skia — equivalent to canvas shadowBlur
const drawGlowLine = (canvas, path, color, glowColor, outerBlur, innerBlur) => {
  // Pass 1: outer diffuse glow
  const glowPaint = Skia.Paint();
  glowPaint.setColor(Skia.Color(color));
  glowPaint.setStrokeWidth(1);
  glowPaint.setStyle(PaintStyle.Stroke);
  glowPaint.setStrokeCap(StrokeCap.Round);
  glowPaint.setStrokeJoin(StrokeJoin.Round);
  glowPaint.setMaskFilter(
    Skia.MaskFilter.MakeBlur(BlurStyle.Normal, outerBlur / 2, true)
  );
  canvas.drawPath(path, glowPaint);

  // Pass 2: tight inner core
  const corePaint = Skia.Paint();
  corePaint.setColor(Skia.Color(color));
  corePaint.setStrokeWidth(1);
  corePaint.setStyle(PaintStyle.Stroke);
  corePaint.setStrokeCap(StrokeCap.Round);
  corePaint.setStrokeJoin(StrokeJoin.Round);
  corePaint.setMaskFilter(
    Skia.MaskFilter.MakeBlur(BlurStyle.Normal, innerBlur / 2, true)
  );
  canvas.drawPath(path, corePaint);
};
Path sampling (pre-compute at mount, not per-frame)
// Sample N+1 equidistant points from an SVG path string
// In RN Skia, use Skia.Path.MakeFromSVGString() + getLength() + getPositionAtLength()
const samplePath = (svgPathString, N = 180) => {
  const path = Skia.Path.MakeFromSVGString(svgPathString);
  const total = path.getLength();
  return Array.from({ length: N + 1 }, (_, i) => {
    const pos = path.getPositionAtLength((i / N) * total);
    return { x: pos.x, y: pos.y };
  });
};

// Pre-compute once, store in useRef (not useState — no re-render needed)
const ptsRef = useRef({
  full: samplePath(FULL_PATH_D),
  w:    samplePath(W_PATH_D),
});
Shape morph (point lerp in worklet)
// morphP is a Reanimated shared value (0 → 1)
const morphP = useSharedValue(0);

// Trigger morph
morphP.value = withTiming(1, {
  duration: 570,  // MORPH_DUR
  easing: Easing.out(Easing.cubic),
});

// In useDerivedValue / Canvas draw callback (runs on UI thread)
const morphedPath = useDerivedValue(() => {
  const p = morphP.value;
  const from = ptsRef.current.full;  // or .w depending on direction
  const to   = ptsRef.current.w;
  const skPath = Skia.Path.Make();
  from.forEach((fp, i) => {
    const tp = to[i];
    const x = fp.x + (tp.x - fp.x) * p;
    const y = fp.y + (tp.y - fp.y) * p;
    i === 0 ? skPath.moveTo(x, y) : skPath.lineTo(x, y);
  });
  return skPath;
});
Half-wave sine blink (pulse phase)
// In a worklet (useDerivedValue or useAnimatedStyle)
const getPulse = (timestamp) => {
  const raw   = Math.sin(timestamp / 1000 * 6);
  const blink = raw > 0 ? raw : 0;   // half-wave: 0 during negative half
  return {
    glowBlur: 4 + 16 * blink,          // 4 → 20
    lineAlpha: 0.60 + 0.30 * blink,    // 0.60 → 0.90
    glowAlpha: 0.55 + 0.45 * blink,    // 0.55 → 1.00
  };
};

// Use Skia's useClockValue() for the timestamp
const clock = useClockValue();
const pulseValues = useDerivedValue(() => getPulse(clock.value));

Path viewBox scaling: The paths are designed for a 360×141 coordinate space. In RN, scale the canvas proportionally to the device width: const scale = screenWidth / 360. Apply via canvas.scale(scale, scale) or a Skia Group transform. Do not re-sample the paths — just scale the canvas.
Handoff: When morphP reaches 1.0, hide the Canvas component and show the static SVG (react-native-svg) in the same render cycle. Since the canvas drew the exact final position just before, there's no visible jump. Fade in the fill area with a 200ms withTiming on opacity.
Pre-compute points: Sample both paths in a useEffect on mount (not during animation). Store in a useRef so they don't trigger re-renders. 181 points = negligible cost, ~5ms.
