React Native (Skia)
Stack: @shopify/react-native-skia for canvas equivalent + react-native-reanimated for animation values. Pre-sample both paths once at mount in a useRef.
// Sample path points once at mount
const samplePath = (svgD, N = 180) => {
  const path = Skia.Path.MakeFromSVGString(svgD);
  const len  = path.getLength();
  return Array.from({length: N+1}, (_,i) =>
    path.getPositionAtLength((i/N)*len));
};

// Morph — runs on UI thread via useDerivedValue
const morphP = useSharedValue(0);
morphP.value = withTiming(1, {
  duration: 570,
  easing: Easing.out(Easing.cubic),
});

const morphedPath = useDerivedValue(() => {
  const p = morphP.value;
  const skPath = Skia.Path.Make();
  fromPts.forEach((fp, i) => {
    const x = fp.x + (toPts[i].x - fp.x) * p;
    const y = fp.y + (toPts[i].y - fp.y) * p;
    i === 0 ? skPath.moveTo(x,y) : skPath.lineTo(x,y);
  });
  return skPath;
});
Glow (two-pass): Draw the path twice — first with MaskFilter.MakeBlur(Normal, blur/2), then again with blur*0.3/2 for the inner core.
Scale: Paths are in 360×141 space. Apply canvas.scale(screenWidth/360, screenWidth/360) — no need to re-sample.

React Native Implementation
Recommended: Use react-native-reanimated's useSharedValue + withTiming for the numeric value, then derive the formatted string in a useDerivedValue. Display via Reanimated's AnimatedText or update via useAnimatedProps on a Text component.
// Net worth counter — 750ms easeOutCubic
const nwValue = useSharedValue(NW_OFF);  // 3753 = ₹37.53Cr

const triggerToggle = (toOn) => {
  nwValue.value = withTiming(toOn ? NW_ON : NW_OFF, {
    duration: 750,
    easing: Easing.out(Easing.cubic),
  });
};

// Derived formatted string
const nwText = useDerivedValue(() =>
  '₹' + (nwValue.value / 100).toFixed(2) + ' Cr'
);

// Staggered cards — delay each by 60ms
CARDS.forEach((card, i) => {
  card.value.value = withDelay(
    i * 60,
    withTiming(toOn ? card.onVal : card.offVal, {
      duration: 600,
      easing: Easing.out(Easing.cubic),
    })
  );
});
"1D" badge: The sub-line format is +₹X.XXL 1D where "1D" is a smaller styled span. During animation, only the numeric portion updates. At animation end (680ms), restore the full styled text.
